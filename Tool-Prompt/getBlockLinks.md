# getBlockLinks - 获取块链接关系

## 功能
获取块的出链（引用的页面）和入链（被引用的情况）列表。

## 参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| blockId | number | ❌ | 块ID（与pageName二选一） |
| pageName | string | ❌ | 页面名称（与blockId二选一） |

## 使用示例
```json
{"blockId": 12345}
{"pageName": "项目A"}
```

## 何时使用
- 查看某页面引用了哪些页面
- 查看某页面被哪些页面引用
- 了解笔记的链接网络

## 返回内容
- 出链列表（该块引用的其他页面）
- 入链列表（引用该块的其他块）

## 注意事项
⚠️ 只返回文本列表，不生成图谱
⚠️ 要看图谱请告知用户使用 `/localgraph` 命令
- 入链数量多时可能只返回部分
