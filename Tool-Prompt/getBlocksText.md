# getBlocksText - 读取块内容

## 功能
按块ID批量获取块的文本内容，包含所有子块。

## 参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| blockIds | number[] | ✅ | 块ID数组 |

## 使用示例
```json
{"blockIds": [123]}
{"blockIds": [123, 456, 789]}
```

## 何时使用
- 已经从搜索结果中获得了块ID
- 需要获取特定块的详细内容
- 需要批量读取多个块

## 注意事项
- 块ID必须是数字类型
- 返回完整的块内容及其子块
- 可以一次读取多个块，更高效
