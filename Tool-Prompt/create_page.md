# create_page - 创建页面

## 功能
创建一个新的页面（通过创建一个空块并为其添加页面别名）。

## 参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| name | string | ✅ | 页面名称（不带 `[[]]`） |

## 使用示例
```json
{"name": "新项目计划"}
```

## 何时使用
- 用户明确要求“创建/新建一个页面”
- 需要一个新的空页面来承载后续内容

## 注意事项
- 如果页面已存在，会提示已存在并返回页面 ID
- 页面名称不能为空，且不能以下划线 `_` 开头
- 创建成功后，返回的 `blockId` 可用于后续 `insert_markdown` 写入内容
