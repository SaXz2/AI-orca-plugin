# get_page - 查找块所属页面

## 功能
根据块ID查找这些块所属的页面。

## 参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| blockIds | array<number> | ✅ | 块ID数组 |

## 使用示例
```json
{"blockIds": [16594, 16595]}
{"blockIds": [123]}
```

## 返回结果
- 页面 ID
- 页面名称
- 是否为日记

## 何时使用
- 当你有一些块 ID，想知道这些块在哪个页面时使用
- 找到某个块在哪个页面中
- 获取页面信息
- 了解块的上下文位置

## 注意事项
- repoId 由插件自动获取，无需传入
- 可以同时查询多个块所属的页面
