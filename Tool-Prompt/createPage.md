# createPage - 创建页面别名

## 功能
为已存在的块创建页面别名，将块提升为独立页面。

## 参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| blockId | number | ✅ | 目标块ID |
| pageName | string | ✅ | 新页面名称 |

## 使用示例
```json
{"blockId": 12345, "pageName": "新项目计划"}
```

## 何时使用
- 用户要求把某个块变成独立页面
- 用户说"把这个提升为页面"

## 注意事项
- 需要先有一个存在的块
- 页面名称不能与已有页面重复
- 这不是创建新内容，只是给块加别名
