# webSearch - 联网搜索

## 功能
联网搜索获取实时信息，查找网络上的内容。

## 参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| query | string | ✅ | 搜索关键词 |
| maxResults | number | ❌ | 最大结果数，默认5，最大20 |

## 使用示例
```json
{"query": "今日新闻"}
{"query": "Python 3.12 new features", "maxResults": 10}
{"query": "2024 NBA finals results"}
```

## 何时使用
- 用户问最新的新闻、事件、数据
- 需要实时信息（天气、股价、比赛结果等）
- 笔记库中没有的外部知识
- 用户明确要求搜索网络

## 搜索技巧
- 用英文搜索效果通常更好
- 关键词精准、简洁
- 实时数据加上时间限定词

## 注意事项
⚠️ **优先使用笔记库工具**查找用户自己的内容
⚠️ 只在需要外部信息时使用此工具
⚠️ 搜索结果可能有时效性
