# get_blocks_text - 读取块内容

## 功能
按块 ID 批量获取块的文本内容（包含所有子块）。

## 参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| blockIds | number[] | ✅ | 块 ID 数组 |

## 使用示例
```json
{"blockIds": [123]}
```

```json
{"blockIds": [123, 456, 789]}
```

## 何时使用
- 已经从搜索结果中获得了块 ID，想读完整内容
- 需要批量读取多个块

## 注意事项
- 块 ID 必须是数字（也可兼容 `orca-block:123` 形式）
- 返回内容会包含子块文本（可能较长）
