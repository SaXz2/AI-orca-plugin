# get_journal_by_date - 获取指定日期日记

## 功能
获取指定日期的日记内容。

## 参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| date | string | ✅ | 日期：`YYYY-MM-DD` 或 `yesterday` |
| includeChildren | boolean | ❌ | 是否包含子块，默认 true |

## 使用示例
```json
{"date": "2026-01-05"}
```

```json
{"date": "yesterday"}
```

## 何时使用
- 用户问“昨天/某一天的日记写了什么”
- 需要回顾指定日期的记录

## 注意事项
- 日期格式必须正确
- 如果该日期没有日记会返回空/未找到提示
