# get_tags_and_pages - 获取标签和页面

## 功能
获取笔记库中的标签列表和页面列表（包含标签的属性定义），用于了解“有哪些标签/页面可以用”。

## 参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| pageNum | number | ❌ | 页码（从 1 开始），默认 1 |
| pageSize | number | ❌ | 每页数量，默认 200，最大 200 |

## 使用示例
```json
{"pageNum": 1, "pageSize": 200}
```

## 返回结果（概念）
- `tags`: 标签列表（name/id/properties）
- `pages`: 页面列表（name/id/created/modified）
- `pagination`: 分页信息

## 何时使用
- 你不确定用户仓库里有哪些标签/页面
- 需要先获取标签 schema（属性名/类型），再决定如何写入/查询

## 注意事项
- 结果可能很多，建议用分页
- 这是“枚举/查看”工具，不会修改任何内容
