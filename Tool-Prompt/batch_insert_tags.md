# batch_insert_tags - 批量添加标签

## 功能
给多个块批量添加一个或多个标签（可选：同时设置标签属性）。

## 参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| blockIds | number[] | ✅ | 目标块 ID 数组（最多 100 个） |
| tags | array | ✅ | 标签数组：可以是字符串，也可以是对象（带属性） |

### tags 支持两种形式
- 字符串：`"Task"`（等价于 `#Task`）
- 对象：`{ "name": "Task", "props": { "状态": "Done" } }`
  - `props` 也可以写成 `properties`

## 使用示例
```json
{"blockIds": [123, 456], "tags": ["Task", "project"]}
```

```json
{"blockIds": [123], "tags": [{"name": "book", "props": {"状态": "reading"}}]}
```

## 何时使用
- 用户要求“给这些笔记打标签/批量标记”
- 需要一次性给多条记录加分类

## 注意事项
- 标签名不需要带 `#`
- `props` 里的属性名和值需要与标签架构匹配
- 如果块已有该标签，可能会更新/覆盖属性（取决于系统行为）
