# get_page_by_name - 读取页面内容

## 功能
根据页面名称获取页面内容（包含所有子块）。

## 参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| pageName | string | ✅ | 页面名称或别名 |

## 使用示例
```json
{"pageName": "项目A"}
{"pageName": "2024-01-15"}
{"pageName": "读书笔记"}
```

## 何时使用
- 用户提到具体的页面名称（如 `[[项目A]]`）
- 用户要求查看某个页面的内容
- 用户问"打开xxx"、"看看xxx页面"
- 读取指定页面的完整内容
- 查看页面的所有子块
- 分析页面结构

## 与 get_page 的区别
- **get_page**: 根据块ID查找所属页面（返回页面信息）
- **get_page_by_name**: 根据页面名称获取内容（返回页面完整内容）

## 注意事项
- 页面名称不带 `[[]]`
- 支持别名匹配
- 返回页面的完整层级结构（包含所有子块）
- 如果页面不存在会返回错误
