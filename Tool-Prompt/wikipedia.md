# wikipedia - 维基百科查询

## 功能
查询 Wikipedia 百科获取权威、准确的背景知识。

## 参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| query | string | ✅ | 搜索关键词 |
| lang | string | ❌ | 语言代码，默认zh（中文） |
| fallback | boolean | ❌ | 没结果时是否尝试其他语言，默认true |

## 支持的语言
| 代码 | 语言 | 说明 |
|-----|------|------|
| zh | 中文 | 默认，本地化内容 |
| en | 英文 | 内容最全面 |
| ja | 日文 | |
| de | 德文 | |
| fr | 法文 | |
| es | 西班牙文 | |
| ru | 俄文 | |
| ko | 韩文 | |

## 使用示例
```json
{"query": "相对论"}
{"query": "Albert Einstein", "lang": "en"}
{"query": "东京", "lang": "ja"}
{"query": "量子力学", "lang": "zh", "fallback": true}
```

## 何时使用
- 用户询问人物、历史事件、科学概念、地理位置等百科知识
- 需要权威、准确的背景信息
- 用户问"什么是"、"谁是"、"介绍一下"等问题

## 语言选择建议
| 场景 | 建议语言 |
|-----|---------|
| 中文查询 | zh（内容可能较少） |
| 英文查询 | en（内容最详细） |
| 科技/学术主题 | en（更全面） |
| 本地化主题（如中国历史） | zh |

## 注意事项
- 不同语言版本内容可能差异很大
- 返回完整词条内容，可能很长
- 长内容会自动分段返回
- 包含图片链接（如果有）
